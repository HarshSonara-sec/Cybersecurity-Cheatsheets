# Linux CLI & Text-Fu Cheatsheet

## Navigation

```bash
pwd    # Current directory
ls     # List files
cd     # Change directory
```

## File Management

```bash
touch  # Create file
mkdir  # Create directory
cp     # Copy
mv     # Move/Rename
rm     # Delete
```

## View Files

```bash
cat
less
head
tail
```

## Search

```bash
find
grep
which
```

## Text Processing

```bash
sort
uniq
wc
cut
tr
```

## Redirection

```bash
>     # Overwrite
>>    # Append
<     # Input
|     # Pipe
2>    # stderr
```

## Key Takeaways

- Use `|` to chain commands.
- Use `grep` to filter output.
- Master redirection for log analysis.
- CLI skills are essential for Linux administration and cybersecurity.
